# Bring Recipes — Android-friendly starter

All website files are kept at the repository root so they are easier to upload
from an Android browser.

## First-time GitHub setup

1. Create a public repository named `bring-recipes`.
2. Extract this ZIP on the phone.
3. In Chrome, open the repository on GitHub.
4. Use **Add file → Upload files** and select every extracted file.
5. Commit the upload to `main`.
6. Open **Settings → Pages**.
7. Choose **Deploy from a branch**, branch `main`, folder `/(root)`.
8. Save.

Expected site:

`https://YOUR-USERNAME.github.io/bring-recipes/`

First recipe:

`https://YOUR-USERNAME.github.io/bring-recipes/qualinesti-vegetable-stew.html`

## Files

- `index.html` — recipe listing
- `qualinesti-vegetable-stew.html` — first recipe
- `styles.css` — shared design
- `AGENTS.md` — persistent Codex instructions
